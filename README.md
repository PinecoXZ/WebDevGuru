# 🚀 WebDevGuru — Elite Digital Experiences & Web Engineering

WebDevGuru is a boutique digital engineering studio crafting high-conversion web platforms, SaaS growth engines, and headless Shopify storefronts for ambitious brands worldwide. Built with sub-second performance, editorial precision, and relentless conversion architecture.

---

## 🏛️ The Aesthetic: Swiss Precision Architectural Engineering

WebDevGuru embodies a single, uncompromising design aesthetic inspired by Swiss International Style and technical flagships:

- **Architectural Carbon Canvas**: Deep carbon backgrounds (`#090a0c` / `#111317` / `#171920`) accented with precision hairline grids and structural borders (`rgba(255, 255, 255, 0.08)`).
- **International Vermilion Accents**: High-visibility vermilion (`#ff3b00`) for interactive focal points, live indicators, and primary callouts.
- **Editorial Typography Pairing**:
  - **Display & Grotesque**: *Syne* paired with editorial italic serifs (*Instrument Serif*).
  - **Body & Interface**: *Plus Jakarta Sans*.
  - **Technical Metadata**: *Space Mono* for latency telemetry, sprint timelines, and live benchmarks.
- **Zero AI-Slop Guarantee**: Strictly no purple blobs, no fake 3D clutter, no layout shifts, and sub-second edge response times.
- **Domain**: [webdevguru.tech](https://webdevguru.tech)

## ⚡ Core Capabilities

1. **High-Converting Flagships**: Full-stack bespoke digital flagships engineered for market authority and commercial conversion.
2. **SaaS Growth Engines**: High-velocity landing pages that translate complex software into visceral value and accelerate trial-to-paid conversion.

---

## 🛠️ Architecture & Tech Stack

- **Core Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8 (with route-level code splitting & rolldown runtime)
- **Icons**: Reicon System (`reicon-react`) with strict weight discipline (`Outline` standard, `Filled` active)
- **SEO & Social Share**: React Helmet Async + Schema.org Structured Data + OpenGraph
- **Telemetry**: PostHog Privacy-Compliant Analytics
- **Typography**: Syne, Instrument Serif, Plus Jakarta Sans, Space Mono

## 🚦 Getting Started

```bash
# Clone the repository
git clone https://github.com/FAYEZ087/webdevguru.git
cd webdevguru

# Install dependencies
npm install

# Start development server
npm run dev

# Run linting
npm run lint

# Production build
npm run build
```
